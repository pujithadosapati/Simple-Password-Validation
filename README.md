# Simple Password Validator
## Project Description
A Python program that checks whether a password meets
basic password-strength requirements.
## Objective
To practice Python strings, conditions, loops,
and input validation.
## Validation Rules
- Minimum 8 characters
- At least one uppercase letter
- At least one lowercase letter
- At least one digit
- At least one special character
## Technologies Used
- Python 3
- string module
## How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run: python password_validator.py
4. Enter a test password when prompted.
## Testing
Tested valid and invalid.
example passwords:
1.Pujitha1234 is invalid password
2.Abac@1234 is valid password
## Security Note
The program does not display the entered password.
This is a basic educational project, not a complete
production authentication system.
## Conclusion
The project demonstrates basic password validation
using Python string methods and conditional statements.
